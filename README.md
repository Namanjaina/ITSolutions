## Contributing
To contribute to the IT Solutions repository, follow these steps:
1. Fork the repository using the command `git fork https://github.com/Namanjaina/ITSolutions.git`
2. Create a new branch using the command `git branch <branch-name>`
3. Make changes and commit them using the command `git commit -m "<commit-message>"`
4. Push the changes using the command `git push origin <branch-name>`
5. Create a pull request to merge the changes into the main repository
